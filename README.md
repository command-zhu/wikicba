# wikicba
for the cba

## LLM Wiki

一个探索大语言模型知识整理与协作的 Wiki 项目。项目刚刚起步，目标、功能和技术方案将随着讨论逐步完善。

## Windows 桌面原型

需要 Node.js 22.12+（建议 24 LTS）。

```sh
npm ci
npm test
npm start
```

`npm start` 构建界面并启动 Electron；`npm run dist:win` 在 Windows 上生成安装包。`npm run dev` 仅运行界面开发服务，没有桌面文件接口。

当前支持项目多目录绑定、默认移动／复制切换、扩展名及关键词规则、规则冲突拒绝、杂物区文件归类、操作日志与条件撤销、四象限待办及拖动、独立置顶窗口与托盘。项目目录列表的第一项为默认目录。双击待办标题编辑；拖文件到待办象限创建关联任务（不搬动文件）。

配置和操作记录暂使用 Electron userData 下的原子替换 JSON 文件，杂物区也在该目录下。原始项目文件仍位于绑定目录。后续可迁移到 SQLite。

### 当前边界

这是开发原型。文件夹拖入目前提示使用绑定入口；目录列表仅展示顶层文件。规则冲突后需在目录列表中手动选择目标。现有待办追加附件、同象限排序、项目／规则编辑、到期提醒、全局快捷键、窗口位置记忆、目录监听、外部 Agent 接口和崩溃恢复队列尚未实现。绑定时一次选择多个目录，暂不支持后续增删。

撤销会检查目标文件内容是否变化，原路径存在时拒绝恢复；默认不覆盖文件。跨盘移动通过复制、内容校验后删除源文件完成。当前校验同步读取文件，适合小规模资料试用，大文件可能阻塞窗口，仍需流式校验与后台任务队列。`pending` 操作记录可供排查，但不自动恢复。

Linux 云环境的构建和文件操作测试不能替代 Windows 上的资源管理器拖拽、托盘、开机启动、跨盘及文件占用测试。请先用测试目录试用，保留重要资料备份。

### 验证

`npm test` 覆盖真实临时目录中的文件操作、规则、持久化，以及模拟桌面桥接的界面表单和悬浮窗导航。`npm run test:desktop` 使用隔离的临时数据运行 Electron 原生冒烟检查，验证 preload、页面渲染、待办 IPC 和悬浮窗创建；需要可用桌面环境。GitHub Actions 在 Windows runner 上执行安装、测试、构建和原生冒烟检查。

当前 Linux 云环境已通过构建及 8 项自动测试；原生 Electron 运行受系统沙箱配置限制，Windows 原生冒烟和手动拖拽验收结果需另行确认。通过自动检查不代表安装包或所有 Windows 行为均已验证。
